# AUREVISTA FUN RIDE 2026

Landing page mobile-first untuk AUREVISTA FUN RIDE 2026.

## Struktur

- `index.html` — halaman utama
- `style.css` — visual/UI responsive
- `script.js` — CTA registrasi + share event
- `images/hero.jpg` — hero campaign
- `images/experience.jpg` — experience section
- `images/venue-layout.jpg` — layout 3D venue asli dari materi event
- `images/community.jpg` — community section
- `images/final-cta.jpg` — final CTA visual

Poster lama yang berisi titik start GBK/Senayan sengaja **tidak disertakan**.

## Sebelum deploy

Buka `script.js` dan ubah:

`const REGISTRATION_URL = "ISI-LINK-PENDAFTARAN-DI-SINI";`

menjadi link registrasi sebenarnya.

## Deploy

Static site; bisa dipush ke GitHub, diimport ke Replit, lalu dideploy melalui Cloudflare Pages.
